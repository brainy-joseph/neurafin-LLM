# NeuraFin: Continuous-Time Liquid Neural Network Engine (In Progress)

NeuraFin is a CPU-native, neuromorphic financial engine for continuous anomaly detection in enterprise audit workflows.

## Research Foundations
- **Liquid Time-Constant (LTC) Networks:** Hasani et al. (MIT CSAIL)
- **Neural Ordinary Differential Equations (ODEs):** Chen et al.

## Key Features
- **Sub-12ms Inference:** Fast CPU-native execution with zero GPU requirements.
- **Continuous Math Core:** Dynamic risk scoring across streaming time-series transactions.
- **Zero-Hallucination Audit Trail:** Combines continuous math outputs with deterministic verification.
